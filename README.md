## What I'm Building Here

Scaling something that already works is harder than it looks, and more interesting than most people admit. That's the professional obsession you just read above. But 0→1 is still the best laboratory there is: nothing sharpens your sense of the possible like building from scratch.

Recently built a fully functional Private Lessons platform prototype using AI-assisted development tools, including Cursor and Claude Code — complete with registration, scheduling, facility management, and responsive interfaces for providers, teachers, and students.

That experience confirmed what I suspected: AI tools have fundamentally changed what a product leader can build independently. I'm using this space to continue exploring that frontier — developing technical fluency, documenting AI-assisted product workflows, and building tools that reflect how modern product teams should work.

Current focus areas:
- Automating product research and synthesis workflows with Claude Code
- Building lightweight prototypes using Cursor and Claude Code to validate fintech, SMB payments, and nonprofit product concepts faster
- Documenting and sharing AI-assisted approaches to product discovery, prioritization, and roadmapping — building a public record of how AI tools are reshaping the product leader's toolkit
